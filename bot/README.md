# Telegram-бот учёта заказов

Бот для продавца на Авито: принимает фото товара и штрихкода, распознаёт трек-номер через OCR, формирует карточку заказа в Telegram-группе и записывает строку в Google Таблицу.

---

## Что нужно уточнить у заказчика перед запуском

1. **Название листа** в Google Таблице (переменная `GOOGLE_SHEET_NAME`).
2. **Значение «Точка продаж»** — название магазина/профиля на Авито (`SALE_POINT`).
3. **Колонка «Контрагент»** — заполнять автоматически одним значением (`COUNTERPARTY`) или оставить пустой?
4. **ID Telegram-группы** для карточек заказов (`GROUP_CHAT_ID`) — добавьте бота в группу с правом отправки сообщений.
5. **Telegram user ID** всех сотрудников, кому разрешён доступ (`ALLOWED_USER_IDS`).
6. **Доступ к Google Таблице** — нужно создать Service Account и выдать ему доступ (см. ниже).

## Установка и запуск

### 1. Зависимости Python

```bash
pip install -r requirements.txt
```

### 2. Tesseract OCR

**Windows:**
- Скачайте установщик с https://github.com/UB-Mannheim/tesseract/wiki
- В установщике выберите дополнительные языки: **Russian** и **English**
- По умолчанию ставится в `C:\Program Files\Tesseract-OCR\tesseract.exe`
- Если путь отличается, добавьте в `.env`:
  ```
  TESSERACT_CMD=C:\путь\к\tesseract.exe
  ```
  И раскомментируйте строку в `services/ocr.py` (см. комментарий внутри файла).

**Linux/Mac:**
```bash
# Ubuntu/Debian
sudo apt install tesseract-ocr tesseract-ocr-rus

# Mac
brew install tesseract tesseract-lang
```

### 3. Google Service Account

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте проект (или выберите существующий).
3. Включите **Google Sheets API** и **Google Drive API**.
4. Перейдите в «IAM и администрирование» → «Сервисные аккаунты» → «Создать сервисный аккаунт».
5. Скачайте JSON-ключ и сохраните как `service_account.json` в папку бота.
6. Откройте вашу Google Таблицу и выдайте email сервисного аккаунта права **Редактора**.

### 4. Настройка .env

```bash
cp .env.example .env
```

Заполните `.env`:

```dotenv
BOT_TOKEN=токен_от_@BotFather
GROUP_CHAT_ID=-100xxxxxxxxxx
ALLOWED_USER_IDS=123456789,987654321
GOOGLE_SPREADSHEET_ID=идентификатор_таблицы_из_URL
GOOGLE_SHEET_NAME=Заказы
GOOGLE_SERVICE_ACCOUNT_FILE=service_account.json
SALE_POINT=Авито
COUNTERPARTY=
```

**Как найти ID Google Таблицы:**
В URL таблицы `https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit` — это часть между `/d/` и `/edit`.

**Как найти ID Telegram-группы:**
Добавьте `@userinfobot` в группу, он покажет ID. Либо используйте `@myidbot`.

**Как узнать свой Telegram user ID:**
Напишите `@userinfobot` или `@myidbot`.

### 5. Запуск

```bash
python main.py
```

## Структура Google Таблицы

Создайте лист с названием из `GOOGLE_SHEET_NAME` и заголовками в первой строке в таком порядке:

| Дата | Трек-номер | Наименование | Количество | Цена продажи за 1 шт | Выручка | Закупка | Траты | Прибыль | Статус заказа | Точка продаж | Статус оплаты поставщику | Контрагент |
|------|-----------|-------------|-----------|---------------------|---------|---------|-------|---------|--------------|-------------|------------------------|-----------|

Бот автоматически добавляет строки. Поля «Цена продажи за 1 шт», «Выручка», «Закупка», «Траты», «Прибыль», «Статус оплаты поставщику», «Контрагент» заполняются вручную в таблице.

## Функциональность

### Сценарий 1 — Новый заказ
1. Отправьте фото товара (или нажмите «➕ Новый заказ»).
2. Отправьте фото штрихкода с трек-номером.
3. Введите название товара.
4. Введите размер.
5. Проверьте распознанные данные и подтвердите или исправьте.
6. Бот отправит карточку в группу и запишет в таблицу.

### Сценарий 2 — Поиск и редактирование
1. Нажмите «🔍 Поиск по трек-номеру».
2. Введите трек-номер (или часть).
3. Выберите заказ из списка совпадений.
4. Нажмите «✏️ Изменить» → выберите поле → введите новое значение.

## Безопасность

- Токен бота и ключ Service Account — только в `.env` и `service_account.json`, не коммитить в git.
- Доступ к боту ограничен allowlist Telegram user ID.
- Добавьте `.env` и `service_account.json` в `.gitignore`.
